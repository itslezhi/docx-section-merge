# 合并交付 QA

先运行 `scripts/verify_coverage.py` 检查每份子文档与模板章节的覆盖；图片、公式、图表、表格数据和嵌入对象检查内容载荷保真；对用户明确指定的 `strict_preserve` 源格式例外，可用 `scripts/verify_preservation.py` 作补充范围比较；该旧辅助脚本不能代替 v3 内容门、有效局部格式检查或逐页视觉验收。随后完成以下检查。脚本通过只是必要条件，不能替代语义审阅和逐页渲染。

## A. 输入与范围

- [ ] 唯一项目模板、全部子文档和输出文件角色无歧义。
- [ ] 已运行 `scripts/extract_template_requirements.py` 扫描当前模板，候选说明已逐条分类且无未复核项；已通读全部可见文字并逐页检查图片/特殊对象中的说明，建立本模板专属 `template_constraints.json`。
- [ ] 模板字数、结构、标点、对应关系、必须项和禁止项均已登记作用域与验证方式；没有把其他模板的示例参数沿用到本项目。
- [ ] 所有适用的模板约束已通过；用户明确覆盖的原约束有原指令与作用域记录；无未解决的适用约束或未经检查就声称通过的项目。
- [ ] 所有输入文件哈希已记录，模板和子文档原文件未被覆盖。
- [ ] 删除范围、子文档内容范围和插入锚点均唯一命中。
- [ ] 语义镜像的联动范围符合用户授权。
- [ ] 已建立完整的“子文档 × 模板章节”覆盖矩阵。
- [ ] 所有普通内容默认使用 template_normalize；总体综合范围使用 synthesize；只有用户明确点名的范围才登记 strict_preserve 源格式例外。
- [ ] 每个写入块已绑定对应的受控移植路径；不存在“通用 clone 后再根据结果清理”的块。
- [ ] 每个新增块已绑定本次母版的段落/运行角色原型；不存在无原型写入、硬编码正文格式或固定表单调用正文格式函数。
- [ ] 标题拆分、标题补齐和编号调整没有自动引入粗体、斜体或字号变化；所有字符强调均有母版同角色证据或用户明确授权。
- [ ] 已建立格式权威矩阵和母版段落角色样本。
- [ ] 已从冻结源文件重新枚举所有内容单元，与 v3 content_register 完整核对；retention 与 uses 分开，无漏登、重复登记、旧状态或未知源块。

## B. 内容保真

- [ ] 覆盖矩阵逐行通过；所有应保留源单元有实际目标，综合 uses 不替代原文 retention；公式结构、位置对应的媒体关系、技术表格单元格及内容载荷分别核验。
- [ ] 用户明确指定的 strict_preserve 例外块数量、顺序、文本和局部格式与冻结清单一致。
- [ ] template_normalize 的删除只包含指纹相等的 exact_duplicate 和有用户授权的 replace_shadow；合并、衔接和格式变化均已登记。
- [ ] 图片媒体、公式语义、图表/嵌入对象数据及表格技术内容无差异；其外层段落、题注、表内文字和版面适配服从模板；固定表单只在授权文字槽位变化。
- [ ] 原样迁入图片的 SHA-256 与源文件一致；获授权修复/改绘图有原图—新图—语义映射记录。
- [ ] 未使用截图替代可编辑内容。
- [ ] 项目模板未授权区域无意外变化。
- [ ] 用户要求删除的简写镜像在授权范围内零残留；允许保留的模板摘要逐项有记录。
- [ ] 每个 exact_duplicate 的指纹已由实际源文件重新计算，未采信计划自填哈希；主题相近、部分重合、互补或更短的内容均未因此删除。
- [ ] 未用“从（4）继续编号”掩盖与（1）—（3）重复的指标或成果。
- [ ] 父标题下没有“技术指标：”“研究目标：”等无上下文的重复导语。
- [ ] 新增衔接段只出现在需要的位置，文本及出现次数均与白名单一致。
- [ ] synthesize 章节逐句可回溯到证据映射，无虚构依赖、接口和指标。
- [ ] 批注模式下，所有模型补齐标题、衔接语、综合编写、跨章节安置和待裁定事项均进入 `review_comments_manifest.json` 并锚定到正文。

## C. OOXML 完整性

- [ ] ZIP 与 XML 均可解析。
- [ ] 所有内部 relationship 目标存在。
- [ ] `[Content_Types].xml` 覆盖完整。
- [ ] 无重复或悬空的关系、书签、drawing、批注、脚注和尾注 ID。
- [ ] 每个新增批注 ID 恰有 `commentRangeStart`、`commentRangeEnd`、`commentReference` 和非空批注正文；批注关系及内容类型闭合，源稿既有批注未被覆盖。
- [ ] 样式与编号依赖闭合，无同 ID 异义覆盖。
- [ ] 每批内容在进入目标包前已通过样式防火墙：template_normalize、payload_preserve 和 synthesize 未导入供体样式；仅登记过的 strict_preserve 例外导入了改名后的非默认局部样式。
- [ ] 模板已有样式、默认样式、主题和兼容设置未被子文档覆盖。
- [ ] 默认段落、字符和表格样式各自只有一个，ID 与母版一致；全部供体新增/重命名样式均不含 `w:default`。
- [ ] 子文档的 `sectPr` 未意外覆盖模板节设置。
- [ ] 固定表单未整格复制子文档段落；表格网格、行列/合并拓扑、单元格属性、段落数和格式骨架符合模板。
- [ ] 固定表单的新增内容按双原型生成：位置布局来自目标单元格，字符格式来自母版共享 fixed_table_value；没有继承填写说明字体，也没有被普通正文默认格式覆盖。
- [ ] 固定槽位已作为 `value_cell` 显式授权并绑定 `value_run_prototype_cell`；所有正式值的有效中文字体、字号、字重和正斜体一致，且没有借授权放宽缩进、行距、对齐或单元格结构检查。
- [ ] 片段级原型差异门已在每次写入后通过；原型未直接声明的字号、字体、缩进等没有被输出擅自写成直接格式。
- [ ] 实际填写值未继承只属于占位说明的斜体、颜色、高亮或下划线；所有保留的强调均有同类已填写模板实例或明确语义依据。
- [ ] 图片显示尺寸不超出目标页面或单元格可用宽度；DrawingML/VML 尺寸同步且宽高比不变。
- [ ] 所有承载长正文的表格行均已检查 `w:cantSplit` 与 `w:trHeight/@w:hRule`；不存在不可跨页的超页高正文行。
- [ ] 定高文本框、形状和内容控件不存在文字溢出；未用缩小字体、负行距或隐藏文字掩盖溢出。

## D. 编号与引用

- [ ] 标题层级和编号连续。
- [ ] 同一父级未混用 `1．`、`（1）`、`1）`、`1.1` 等不同编号族。
- [ ] 分项编号在严格完全判重和用户授权替换后生成，子文档边界没有造成无依据地重新从（1）开始。
- [ ] 编号标题与编号正文项已按语义角色区分；嵌套父标题和直属子项没有复用同一编号族造成作用域冲突。
- [ ] 图、表、公式编号符合模板规则。
- [ ] 每处交叉引用指向正确对象。
- [ ] 文献按身份去重并按首次出现顺序编号。
- [ ] 正文引文与参考文献一一闭合；若用户明确保留无条目的原稿引文，已逐项列为例外且未声称闭合。
- [ ] 目录/图表目录/域无错误或陈旧显示值。

## E. 格式检查

- [ ] 已对每个固定表单运行 `scripts/audit_template_format.py`，无未授权漂移。
- [ ] 已在每份子文档或复杂对象批次后运行 `scripts/style_firewall.py`；失败批次已从最近一次通过的临时包重做，没有在污染文件上逐字段补偿。
- [ ] 模板固定标签、提示和占位槽位没有新增段落、段首空格、制表符、异常字距或子文档缩进。
- [ ] 未替换的模板原有短字段（例如“与封面一致”）整段 XML 与母版一致，并在实际渲染中起始位置一致。
- [ ] 普通正文的完整缩进属性集与本次母版正文原型一致；若母版同时声明字符缩进和兼容 twip 缩进则两者均原样保留，不能以通用规则否定或删改母版属性；不得用两个空格模拟首行缩进。
- [ ] 承担正文陈述功能的编号项使用母版正文角色缩进；没有因为带编号前缀而被误判为标题并清除缩进。
- [ ] 标题、分项标题、列表、题注、公式行、表格字段和参考文献未被误套正文首行缩进。
- [ ] 同级分项标题的有效字重一致；由模型拆出或补齐的标题没有脱离母版角色而被硬编码加粗。
- [ ] 中文字体与模板一致；拉丁字母、数字和西文标点使用规定西文字体，要求时为 Times New Roman。
- [ ] 参考文献编号、悬挂/首行缩进、行距、段距、字号和中英文字体一致。
- [ ] 参考文献编号的有效字重一致；审计已解析字符样式和 `basedOn/docDefaults` 继承，不只检查直接 `<w:b>`。
- [ ] 普通正文不存在子文档遗留的校改红色、随机加粗、分散对齐或直接格式异常；所有例外均有语义依据。

## F. 视觉检查

- [ ] 已渲染全部页面并逐页查看。
- [ ] 图片未丢失、拉伸、裁切、漂移或遮挡正文。
- [ ] 图题/表题与对象相邻，分页合理。
- [ ] 表格无断裂、越界、字体替换或单元格溢出。
- [ ] 插入的同级技术表格共享同一 `technical_table` 横向位置角色；紧凑表格相对正文容器居中且无供体左缩进残留。
- [ ] 可在一页容纳的短表与其题注位于同一页，整表未跨页；供体浮动定位未导致后文绕排到表格左右。单页无法容纳的长表只在允许的行边界分页并重复表头。
- [ ] 固定表单与母版并排比较，短字段的起始位置、字符疏密、换行、行高和垂直位置一致。
- [ ] 图中箭头在框边界结束，框、箭头、文字和图例无重叠、裁切或穿越。
- [ ] 折线箭头末段方向和长度通过几何门；箭头包围盒未覆盖前一水平段、折点或其他箭头，并已局部放大复核。
- [ ] 新绘/改绘总体图在最终 A4 显示尺寸下清楚可读，并与正文术语及关系一致。
- [ ] 每个长内容块的末尾哨兵文本既存在于 DOCX XML，也能从渲染输出中提取并在对应页面看见。
- [ ] 页眉页脚、页码、纸张、页边距保持模板规则。
- [ ] LibreOffice 逐页渲染通过后已单独完成 Word/WPS 表格分页结构审计；目标编辑器可用时已抽查所有跨页正文行。
- [ ] 最终 DOCX 能由 Word/LibreOffice 正常打开。
- [ ] 已提取并逐条核对审阅批注；批注与清单类别、锚点、来源和人工裁定事项一致。headless 渲染未显示批注气泡时仍完成 OOXML 结构审计。

## G. 禁止的替代验收

- [ ] 未用少量“必含句”代替完整块指纹和覆盖矩阵。
- [ ] 未用全局图表/OLE 总数代替按“子文档 × 模板章节”的对象位置核对。
- [ ] 未用“文件可打开”或“关系无断裂”代替内容与版式验收。
- [ ] 未因 LibreOffice 能自动拆分超长表格行，就忽略 Word/WPS 对 `w:cantSplit` 或定高容器的不同处理。
- [ ] 未因 XML 文本没有普通空格，就忽略缩进、字距、分散对齐、额外段落或行高造成的视觉空白。
- [ ] 未把格式异常字段逐个显式补丁化，以掩盖供体样式、默认样式、主题或字体表越过母版边界。
- [ ] 自动回填的确定字段均记录权威来源、目标位置和冲突检查；未把示例、提示或不确定推断当作事实。
- [ ] 内容覆盖与格式验收分别通过；默认保留的源块全部可追溯，严格重复/授权镜像的删除证明完整，同时未把逐字出现当作模板格式正确的替代品。

所有适用项通过后才可交付。用 merge_pipeline.py release 检查绑定当前候选哈希的机器报告、真实审阅证据和逐页 PNG；review 可以保留已按契约批注的未决项，final 要求裁定全部解决。不得把 skipped 或 pending 填成 passed。
