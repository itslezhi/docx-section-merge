# 表格与定高容器的分页守卫

## 适用场景

供体正文将进入主文档的表格单元格、文本框、形状或内容控件时使用。项目申报模板常把整章放在一行一格的表单中，并预设一页高的最小行高及“禁止跨页”；占位稿看似正常，迁入长正文后可能在 Word/WPS 中从页底开始不可见。

## 1. 写入前记录容器属性

对每个目标容器记录：

- 表格、行、单元格的真实 OOXML 路径；
- `w:trPr/w:cantSplit`；
- `w:trPr/w:trHeight` 的值及 `w:hRule`（`exact`、`atLeast` 或自动）；
- `w:tcFitText`、`w:noWrap`、嵌套表格、图片和 OLE；
- 文本框/形状的高度、自动适应文字设置和溢出行为；
- 页面可用高度，以及写入前后的段落、字符、表格、图片和公式数量。

`w:tblLayout w:type="fixed"` 主要控制列宽，不能替代纵向分页检查。`hRule="atLeast"` 本身不是固定高度，但与 `w:cantSplit` 及超页内容组合时仍可能被不同编辑器裁切。

## 2. 风险判定

以下任一情况必须在写入前处理，不能等视觉预览碰运气：

1. 目标行含 `w:cantSplit`，而供体块按字符、段落、图片或嵌套表格判断可能超过一页；
2. 行高为 `exact`，新增内容可能超过该高度；
3. 文本框或形状定高且未启用随文字扩展；
4. 合并后正文末尾仍在 XML 中，但渲染文本或目标编辑器页面中找不到；
5. LibreOffice 与 Word/WPS 的页数、表格断点或可见尾文不一致。

写入前和临时输出上均运行：

```bash
python scripts/inspect_docx.py input.docx --summary-only --fail-on-pagination-risk
```

该检查是保守预警，不代替逐页查看。命中后应核对具体目标行，而不是无条件修改整份模板。

## 3. 修复优先级

仅在用户授权的合并目标范围内处理。模板既有表格列宽、单元格合并、边框和底纹默认保持；正文段落继续使用模板对应角色格式，不保留供体段落格式。若为解决不可见文字必须改变模板容器属性，只允许采用下列最小修改，并记录原因与前后差异。

1. **普通长正文行**：删除该行的 `w:cantSplit`，保留 `atLeast` 最小高度，使正文自然跨页。
2. **带 `exact` 高度的长正文行**：若精确高度不是必须的表单签字区，改为 `atLeast`；如精确高度属于模板控制项，则把正文拆入具有相同列宽和边框的续接行。
3. **复杂对象集中行**：在语义边界处分为续接行，确保图片、题注、公式和嵌套表格不被拆散。
4. **定高文本框/形状**：优先启用随文字扩展或改为正文流；只有用户允许时才改变对象类型。

把供体浮动表格改回正文流只解决分页和绕排，不代表横向位置已经规范。完成本文件的分页处理后，仍必须按 [格式规范化](format-normalization.md) 的 `technical_table` 角色设置整表对齐、缩进和宽度；不得让缺失的 `w:jc` 回退为编辑器默认左对齐。

### 3.1 题注与短表作为原子分页块

先判断表格是“可在一页内完整容纳的短表”还是“自身必然跨页的长表”，不能把两者混用一套规则。

对题注与整表能够在一页内放下的短表：

1. 除非母版同角色原型明确授权，删除供体 `w:tblpPr` 等浮动定位及文字环绕，让表格回到正文流；
2. 题注段设置 `keepNext`，各行设置 `cantSplit`；必要时把除最后一行外的表内段落连接为 `keepNext` 链；
3. 先让排版引擎自然把“题注 + 整表”移到下一页。若目标编辑器仍拆分，在最终分页稳定后才对题注使用 `pageBreakBefore` 或无边框单元容器作为局部修复；
4. 复核表后正文必须从表格下方继续，不能绕排到表格左右，也不能被表格遮挡。

对单页无法容纳的长表：保持流内表格，禁止单行在页间截断；在允许的行边界分页并重复表头。不得为追求“整表不跨页”缩小到不可读、压缩字距或制造大片异常空白。

禁止通过缩小字体、字符压缩、负行距、隐藏文字、白色字体或扩大到页脚区域来“容纳”内容。

## 4. 双引擎验收

LibreOffice 渲染仍用于逐页视觉 QA，但其能够显示尾文并不能证明 Word/WPS 也会正确分页。必须同时完成：

- 结构断言：长正文目标行无 `w:cantSplit`，不存在不合理的 `exact` 行高；
- 尾文断言：为每个移植块保存末尾 20—50 字哨兵，确认其存在于 DOCX XML；
- 渲染断言：哨兵能够从渲染 PDF/文本中提取，并在逐页 PNG 中可见；
- 短表断言：题注与整表位于同一页，表后正文不在表格左右绕排；
- 表格定位断言：输出中的浮动表格均能回溯到母版同角色原型或用户明确授权，供体浮动定位零残留；
- 目标编辑器可用时，用 Word/WPS 抽查跨页行；不可用时明确说明未完成原生引擎复核，不得仅凭 LibreOffice 声称兼容。

## 5. 本类故障的识别特征

若页面底部出现表格横线，正文恰好在横线处截断，而同一段后文仍存在于 `word/document.xml`，通常不是“文字未复制”，而是正文被放入不可跨页或定高容器。此时应修复容器分页结构，不应重新输入或改写正文。
