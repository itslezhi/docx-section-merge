# 技术图件生成、修复与嵌入

## 1. 先决定处理模式

对每张图明确选择：

- `preserve`：语义和版式均合格，仅迁移并适配版心；
- `repair`：语义正确，但存在箭头压框、文字裁切、对象漂移、字体过小或层级混乱；
- `redraw`：原生对象无法稳定修复，按原图语义重绘；
- `generate`：总体章节需要新图，且节点与关系已由证据映射确认。

未经授权不得把 `preserve` 升级为改绘。原图含义不明或修复会改变关系时保留原图、暂停该项改绘并询问；继续其他确定内容。

## 2. 建立图件语义清单

在动图前记录：

- 节点、分组、层级和节点内文字；
- 连接方向、反馈、条件、循环和图例；
- 与正文分项、输入输出、指标和验证步骤的对应关系；
- 原题注、正文引用、编号和插入位置；
- 原图类型、可编辑性、画布、尺寸和媒体哈希。

`redraw` 和 `generate` 必须使用已确认的节点表与边表。不得添加装饰性箭头来暗示不存在的技术关系。

## 3. 新画总体图

总体方案正文和证据映射稳定后，调用 `minimal-card-flowchart`：

1. 依据真实关系选择分层架构、模块关系、闭环或阶段流程；
2. 节点名与正文术语逐字一致；
3. 每条箭头都有来源证据或明确的综合逻辑；
4. 优先生成可编辑 SVG，并保留图源；
5. 在 A4 最终显示宽度下控制文字长度、节点密度和线宽；
6. 题注与正文引用进入全局编号映射。

图的目的在于解释结构和关系，不为追求对称而增加层级、节点或接口。

## 4. 修复已有图

按以下顺序处理：

1. 扩大或重排画布，保持节点的技术分组；
2. 调整节点尺寸和文字换行，避免文字裁切；
3. 将连接线绑定到正确连接点，使箭头终止于框边界而非进入框内；
4. 调整路径、折点、跨越与 z-order，避免线穿过节点或文字；
5. 统一同级节点、字体、线宽和间距；
6. 原生形状跨 Word/WPS 不稳定时，按语义清单重绘为可编辑 SVG。

修复只改变视觉表达，不改变节点、方向、循环、图例和条件。任何语义变化必须返回总体证据映射重新确认。

### 4.1 箭头和折线连接器的几何门

连接器不能只检查端点坐标；必须把线宽、箭头标记尺寸、折点和节点边界一起计算。

- 正交折线的箭头方向由最后一段决定。向下箭头前必须存在独立的向下末段，不能把箭头叠在上一段水平线或折点上。
- 末段有效长度必须大于箭头沿轴向的实际长度，并额外留出至少 `max(2 × 线宽, 4 个 viewBox 单位)` 的净空。使用 `markerUnits="strokeWidth"` 时先乘上线宽计算实际箭头尺寸；无法稳定计算时改用 `markerUnits="userSpaceOnUse"` 固定尺寸。
- 箭头包围盒不得与上一段、折点、另一箭头或无关节点相交；箭头尖端落在目标框连接点，箭尾仅覆盖末段。
- 多条线进入同一框时使用分离的连接点或具有足够间距的汇流线；每个箭头前仍保留独立末段。
- 线与节点的 z-order 不能掩盖几何错误。不得依靠把框盖在线上、把箭头置顶或裁切来伪装正确连接。

对 `generate` 和 `redraw` 图件生成 `connector_geometry` 记录，至少保存每条边的路径、末段方向与长度、实际箭头轴向长度、目标连接点和相交检查结果。任一末段净空或相交检查失败即禁止嵌入 Word。

## 5. Word 嵌入规范

- 依据页面或单元格可用宽度等比例缩放，不拉伸；
- DrawingML 与内部变换尺寸同步，保留裁剪参数；
- 优先内嵌并与题注保持相邻；需要浮动时保留锚点、环绕和层级并跨编辑器验证；
- 不以低清截图替代可编辑图源；
- 图源、最终媒体、语义清单和旧图—新图映射进入 QA 记录。

## 6. 验收清单

- 箭头在节点边界结束，不压框、不进入文字区；
- 每个带箭头折线的末段方向正确且长于箭头本体与净空之和，箭头包围盒不与前一段或折点相交；
- 框、箭头、文字和图例无重叠、裁切、穿越或越界；
- 方向、反馈、分组和图例与正文一致；
- A4 页面 100% 缩放下文字可读，宽高比不变；
- 图题紧邻图件，分页合理；
- 图号、正文引用和图目录同步；
- Word/WPS 与可用的 headless 渲染中无明显漂移。
- 对箭头、折点和连接点进行局部放大复核；整页缩略图不能作为唯一验收证据。
