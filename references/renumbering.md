# 编号、交叉引用与参考文献同步规则

## 总原则

先完成用户授权的简写替换、严格完全判重、内容移植和获授权的综合图件，再按最终文档顺序建立“旧标记 → 新标记”映射。每一类编号必须同时修改定义处与全部引用处，并保存带来源作用域和对象身份的 v3 numbering_map 用于 QA。禁止使用屏蔽所有编号后的文字相等来代替引用身份核验。不得借编号处理删除部分重合但不完全相同的内容。

## 1. 标题编号

- 识别标题是 Word 多级列表、域，还是手工文本前缀。
- 优先沿用主文档在插入位置的层级与编号格式，例如 `一、`、`（一）`、`1.`、`1.1`、`1.1.1`。
- 只替换编号前缀，不修改标题正文。
- 对供体中不完整或跳级的小标题，不擅自补标题；只在最终层级映射唯一时重编号。
- 若主文档混用自动编号和手工编号，先确定目标章节的主导方式，不在同一层级继续混用。

## 1.1 分项层级与连续编号

从母版抽取一棵 `numbering_schema`，例如：

- 一级章节：`一、`；
- 二级条目：`1．`；
- 三级分项：`（1）`；
- 四级子项：`1）`；
- 更深层级：仅在母版实际使用时采用 `①` 或 `1.1.1`。

这只是示意，最终以母版为准。同一父级下只使用一个编号族，不能把供体的 `（1）`、`1）`、`1.` 和 `1.1` 混在同一层。

对合并列表：

1. 按合并契约核验完全重复或用户明确授权的简写替换；语义身份只帮助定位候选；
2. 父标题与纯结构导语重复时，登记结构映射；含有实质信息的导语仍保留，不能以冗余为由直接删除；
3. 将独立保留项按最终顺序连续编号；
4. 只有通过完全重复证明或用户明确授权的简写替换，才由被保留实例承接编号；“被更完整版本覆盖”本身不是删除依据；
5. 只有真正新增的独立条目才从下一序号继续。

来源文件边界不等于编号边界。编号服务于最终章节结构，不用于标记来源身份或分项名称。

## 1.2 嵌套编号作用域冲突

同一局部层级中，父级小标题和其直属子项不得使用相同编号族而造成作用域歧义。例如父标题已经使用 `①`，其下并列定义项不应再次从 `①` 开始。处理顺序为：

1. 先根据母版 `numbering_schema` 和相邻同级实例确认真实父子关系；
2. 父级编号保持所在层级，直属子项改用母版定义的下一层编号族；
3. 同一父级下连续编号，进入新的同级父项后可按母版规则重新起号；
4. 同步更新正文中对这些子项的明确引用，但不对普通数字做全局替换；
5. 母版没有更深层级且语义无法唯一判断时，保留内容并列为人工复核，不擅自发明层级。

## 2. 图、表和公式编号

- 分别按最终出现顺序编号；章节编号制与全文连续制沿用主文档。
- 题注若使用 `SEQ` 域，重建或更新域与书签；若为手工文本，精确修改题注编号并更新对应正文引用。
- 题注标题正文不变，图片字节不变。
- “图1-2”“图 1”“图（1）”等格式必须匹配主文档既有格式。
- 若正文出现“下图”“上表”等非编号指代，不改写。

## 3. 正文交叉引用

为每个题注、标题、公式建立稳定对象键，优先用书签；没有书签时用“对象类型 + 原题注全文 + 原文档位置”生成临时键。

逐个更新：

- `REF`、`PAGEREF` 等域；
- 手工输入的“见图X”“如表X所示”“式（X）”；
- 目录和图表目录中的缓存显示值。

不得做无上下文的全局数字替换。

## 4. 引文与参考文献

### 4.1 建立文献身份

按以下优先级识别同一文献：

1. DOI、标准号、专利号或其他唯一标识；
2. 规范化标题 + 年份；
3. 第一作者 + 规范化标题；
4. 无法确认时视为不同文献并标记待核验，不凭相似标题合并。

### 4.2 合并与编号

1. 收集最终正文中实际出现的全部引文；
2. 从主文档和供体参考文献表提取对应条目；
3. 按文献身份去重；
4. 按最终正文首次出现顺序赋新编号；
5. 更新单个引文、并列引文和范围引文，例如 `[3]`、`[3,5]`、`[3-5]`；
6. 重新生成或调整参考文献表序号，但不擅自改写条目内容；
7. 检查每个正文编号恰好对应一个条目，且每个保留条目至少被引用一次，除非模板要求保留未引文献。

不得对所有供体引文统一加一个偏移量：主文档和供体可能有重复文献，且首次出现顺序可能交错。

### 4.3 特殊情况

- Word 引文域或文献管理器字段：保留字段结构并更新缓存；不能安全更新时停止并报告。
- 脚注/尾注引文：先迁移脚注/尾注部件并重映射 ID，再处理显示编号。
- 供体正文有引文但未提供对应参考文献条目：不得编造，默认向用户索取或标记阻塞。若用户明确要求“正文和现有引文标记原样保留、缺失条目不补写”，则保留这些标记且不把它们纳入可确认文献的重编号映射，在 QA 中逐项列为“原稿缺失条目、按用户指令保留”；不得声称引文与参考文献已闭合。

## 5. 目录和域

- 目录不手工逐行重写，优先保留/重建 `TOC` 域并设置打开时更新。
- headless 渲染无法可靠刷新时，可为 QA 物化必要的 `SEQ/REF` 显示值；正式文档如需可更新域，保留域代码。
- 最终检查不得出现“错误！未找到引用源”“Error! Reference source not found.”或空白题注号。
